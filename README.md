 Core Deliverable: Interactive To-Do List
The root directory contains a fully functional, responsive To-Do List application built using pure vanilla
JavaScript and CSS.
Add Tasks: Type tasks into the input field and press Enter or click Add.
Toggle Completion: Click on any task item to mark it as complete or incomplete with a strikethrough.
Delete Tasks: Hover over a task and click the delete button to remove it from state.
Filter Tasks: Seamlessly toggle between All, Active, and Completed filter views.
Dynamic Stats: Real-time counter tracking remaining active tasks and a batch clear button for
completed tasks.

 Lessons & Practice Overview
Lesson 9: Understanding the DOM
Practices element selection via getElementById , getElementsByClassName , querySelector , and
querySelectorAll . Explores DOM tree traversal (parents, children, siblings) and dynamic node
creation/insertion.
Lesson 10: Events & User Interaction
Covers event listeners, extracting event object properties (coordinates, target elements), implementing
event delegation on parent lists, and real-time form validation with keyboard shortcuts ( Ctrl + S ,
Escape ).
 Daily Challenges Breakdown
Day 1 (Color Changer): Randomizes header text color on button click.
Day 2 (Dynamic Element Creator): Appends numbered paragraphs with individual delete buttons.
Day 3 (Image Remover): Toggles display visibility for images across the page.
Day 4 (Content Copier): Replicates live typing from an editable source container to a target box.
Day 5 (Dark Mode Toggle): Switches document-level background and text color themes smoothly.
 Setup & Usage
Clone the repository, open index.html in your browser to test the To-Do List app, or open dompractice.html and the files in daily-challenges/ to review practice exercises.
